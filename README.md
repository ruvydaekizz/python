# Python Eğitim ve Çalışma Deposu

Bu depo, temel Python programlamadan veri analizine ve yapay zeka makine öğrenmesi modellerine kadar çeşitli konularda örnek kodlar, alıştırmalar ve proje dosyaları içermektedir.

## 📁 Klasör Yapısı ve İçerikler

### 1. AI-bootcamp 
**İş Yaşamında Eşit Fırsatlar Programı Yapay Zeka Eğitimi** kapsamında işlenen konuları ve örnek uygulamaları içerir:
* API CRUD işlemleri
* Nesne Yönelimli Programlama (OOP)
* Pandas ile Veri Analizi (Pandas Data Analysis)
* Basit Doğrusal Regresyon (Simple Linear Regression)
* Çoklu Doğrusal Regresyon (Multiple Linear Regression)

### 2. Python Basics
Python'a giriş ve temel programlama yapı taşları bu klasörde yer almaktadır:
* Temel eğitim dosyaları (`python101.py`, `python201.py` vb.)
* Veri yapıları (`data_structures.py`)
* Fonksiyonlar, koşullu ifadeler ve döngüler
* Alıştırma ve tekrar dosyaları (`python_alistirma1.py`, `python_recap.py` vb.)
* Modül kullanımı (`HesapModulu.py`) ve mini projeler.

### 3. OOP (Nesne Yönelimli Programlama)
Python'da OOP prensiplerinin adım adım işlendiği detaylı çalışma dosyaları:
* Sınıflar (Classes)
* Kapsülleme (Encapsulation)
* Kalıtım/Miras Alma (Inheritance)
* Soyut Sınıflar (Abstract Classes)
* Metod Ezme (Overriding)
* Çok Biçimlilik (Polymorphism)
* *Örnek Uygulama: Hesap Makinesi*

### 4. Veri Bilimi ve Görselleştirme Kütüphaneleri
* **NumPy:** Temel NumPy operasyonları ve indeksleme işlemleri.
* **Pandas:** Pandas kütüphanesine giriş, temel metotlar ve veri işleme uygulamaları.
* **Matplotlib:** Veri görselleştirme; çizgi (line) ve dağılım (scatter) grafikleri oluşturma.
* **Data Analysis with Python:** Çalışma ortamının kurulması (`setting_up_working_environment`) ve temel veri analizi komutları.
